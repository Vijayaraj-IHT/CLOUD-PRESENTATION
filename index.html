01 · FUNDAMENTALS

How your file actually travels

From the moment you hit upload, your file makes a journey most people never think about.

TYPE 01

Object storage

Hover / Click to reveal →

OBJECT STORAGE

Stores files as whole, self-contained units with metadata. Think: Google Photos, Amazon S3. Best for unstructured data — images, videos, backups.

TYPE 02

Block storage

Hover / Click to reveal →

BLOCK STORAGE

Splits data into fixed-size blocks, each addressed independently. Think: Amazon EBS. Powers virtual machines and databases that need fast read/write.

TYPE 03

File storage

Hover / Click to reveal →

FILE STORAGE

Organizes data in a familiar folder/file hierarchy shared across users. Think: Google Drive, Amazon EFS. Best for shared documents and collaboration.

02 · THE ENGINE ROOM

What keeps your file alive

DURABILITY STAT

99.999999999%

("11 nines")

Eleven nines of durability. At that rate, if you stored 10 million files, you'd expect to lose one roughly once every 10,000 years.

APIs & SDKs

Every time an app like Instagram or Netflix fetches a photo or video, it's making a request to cloud storage through an API — a structured way for software to ask, 'give me this file.'

Redundancy & Replication

The moment you upload a file, it's copied — automatically — across multiple physical servers, often in different buildings or even different cities.

If one server fails? You'd never know. The other copies keep your data available without interruption.

CASE STUDY

Netflix on AWS

Netflix streams to over 300 million subscribers worldwide without owning a single data center — every video, recommendation, and account detail is served through Amazon's cloud infrastructure. It's a working example of why 'don't manage your own servers' became the industry default.

THE FLIP SIDE

Cloud storage isn't risk-free

  • Vendor lock-in
  • Latency & bandwidth cost
  • Data sovereignty

Uploading is almost always free — downloading it back out is where the bill shows up. Egress pricing (roughly $0.09/GB on AWS S3 once you're past the free tier) is the gotcha that catches most students the first time a side project gets real traffic.

⚠ REAL INCIDENT

In 2017, a misconfigured Amazon S3 bucket exposed sensitive voter data for nearly 200 million Americans — not because of a hack, but because access permissions were left open by mistake. The technology wasn't the failure; the configuration was.
