## ✨ Features

- 🎞️ Slide deck rendered entirely in the browser
- ✨ Smooth transitions via **anime.js**
- 🎨 Utility styling with **Tailwind CSS**
- 📦 Bundles to a **single HTML file** via `vite-plugin-singlefile`
- 🧩 `src/utils/cn.ts` — className merge helper (clsx + tailwind-merge)

## 📁 Structure

```
src/
├── App.tsx        # 🎞️ slide deck
├── main.tsx
├── index.css
└── utils/cn.ts
```

---

## 🚀 Getting Started

```bash
npm install       # install dependencies
npm run dev       # → local dev server
npm run build     # production build (single-file)
npm run preview   # preview the build
```

| Command | Action |
|---|---|
| `npm run dev` | Start Vite dev server |
| `npm run build` | Build for production |
| `npm run preview` | Preview the build |
